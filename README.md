# ربات تلگرامی مدیریت فروشگاه 🧾

ربات تلگرامی کامل برای صدور فاکتور، مدیریت فاکتورها، گزارش‌های مالی، CRM،
مدیریت محصولات/انبار و تنظیمات، همراه با یک پنل وب گرافیکی (Telegram WebApp)
مشکی با خطوط نئون RGB.

## ساختار پروژه

```
shop_bot/
├── main.py                    # نقطه ورود - فقط register_* هر فاز را صدا می‌زند
├── config.py                  # تنظیمات کلی (توکن، ادمین، مسیرها)
├── requirements.txt
├── .env.example
├── database/
│   ├── db.py                  # اتصال SQLite + Session + init_db
│   └── models.py               # مدل‌های SQLAlchemy (Customer, Product, Invoice, ...)
├── handlers/
│   ├── core_handlers.py       # منوی اصلی مشترک - پل بین همه فازها
│   ├── invoice_handlers.py    # فاز ۱: فاکتور جدید
│   ├── invoice_management.py  # فاز ۲: مدیریت فاکتورها
│   ├── reports_handlers.py    # فاز ۳: گزارش‌های مالی
│   ├── crm_handlers.py        # فاز ۴: مدیریت مشتریان
│   ├── product_handlers.py    # فاز ۵: محصولات و انبار
│   └── settings_handlers.py   # فاز ۶: تنظیمات
├── utils/
│   └── invoice_file.py        # تولید تصویر/متن/PDF فاکتور
└── webapp/
    ├── web_server.py          # سرور Flask پنل وب گرافیکی
    ├── templates/dashboard.html
    └── static/
        ├── theme.css          # تم مشکی + خطوط نئون RGB
        └── fonts/             # فونت وزیرمتن را اینجا اضافه کنید (README.txt را ببینید)
```

## نصب

```bash
python3 -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

فونت وزیرمتن را طبق راهنمای `webapp/static/fonts/README.txt` دانلود و اضافه کنید
(اختیاری، ولی برای نمایش درست فارسی در تصویر/PDF/نمودار لازم است).

## تنظیمات

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید (یا مستقیماً متغیرهای
محیطی را ست کنید):

```bash
cp .env.example .env
```

مقادیر زیر را پر کنید:
- `BOT_TOKEN`: توکن ربات از @BotFather
- `ADMIN_ID`: آیدی عددی تلگرام شما (از @userinfobot)
- `WEBAPP_URL`: آدرس عمومی **HTTPS** پنل وب (تلگرام Web App فقط با HTTPS کار
  می‌کند - برای تست لوکال از ابزاری مثل ngrok استفاده کنید و آدرس آن را اینجا
  بگذارید، مثلاً `https://xxxx.ngrok-free.app/dashboard`)
- `WEBAPP_PORT`: پورت داخلی Flask (پیش‌فرض 5000)

اگر از `.env` استفاده می‌کنید، قبل از اجرای `main.py` آن را load کنید (مثلاً با
`python-dotenv` یا `export $(cat .env | xargs)` در لینوکس/مک).

## اجرا

```bash
python main.py
```

این دستور همزمان:
1. دیتابیس SQLite را می‌سازد (در صورت نبود)
2. ربات تلگرام را با polling اجرا می‌کند
3. سرور Flask پنل وب گرافیکی را در یک ترد پس‌زمینه روی `WEBAPP_PORT` بالا می‌آورد

برای اینکه دکمه «📊 داشبورد گرافیکی» در تلگرام کار کند، باید پورت Flask از طریق
یک دامنه HTTPS واقعی (یا تانلی مثل ngrok) به بیرون exposed شود و همان آدرس در
`WEBAPP_URL` قرار بگیرد.

## نکات مهم درباره‌ی سینک نهایی

در بازبینی نهایی این باگ‌ها/ناهماهنگی‌ها بین فایل‌ها پیدا و رفع شد:

1. **فایل `Models.py` با حرف بزرگ ولی import‌ها `database.models` (حرف کوچک)
   بودند** — روی لینوکس (حساس به کوچک/بزرگی حروف) اجرا نمی‌شد. به `database/models.py`
   منتقل شد.
2. **فازهای ۲ تا ۶ اصلاً قابل دسترس نبودند** — `main.py` قبلی فقط دکمه‌ی
   «🧾 فاکتور» را نشان می‌داد و منوهای `inv_mgmt_menu` / `report_main` /
   `crm_menu` / `product_menu` / `settings_menu` هیچ‌جا لینک نشده بودند. یک
   منوی اصلی مشترک (`handlers/core_handlers.py`) اضافه شد که به همه‌ی فازها
   لینک می‌دهد، و دکمه‌ی «🏠 منوی اصلی» به منوی هر فاز اضافه شد.
3. **باگ جستجوی فاکتور در فاز ۲**: `Invoice.customer.full_name.ilike(...)`
   روی یک relationship معتبر نبود و کرش می‌کرد؛ به `Customer.full_name.ilike(...)`
   با import صحیح `Customer` اصلاح شد.
4. **مسیر بک‌آپ دیتابیس هاردکد شده بود** (`"backups"` نسبی) به‌جای
   `config.BACKUP_DIR`؛ اصلاح شد تا مستقل از مسیر اجرا همیشه درست کار کند.
5. **`WEBAPP_URL` در `config.py` تعریف نشده بود** و `settings_handlers.py`
   با یک مقدار hardcoded پیش‌فرض کار می‌کرد؛ به `config.py` اضافه شد و از
   متغیر محیطی خوانده می‌شود.
6. **پنل وب Flask هیچ‌جا اجرا نمی‌شد** — به `main.py` اضافه شد تا در یک ترد
   پس‌زمینه همراه با ربات بالا بیاید (`webapp/web_server.py` هم‌چنان مستقل
   هم قابل اجراست).
7. ساختار پکیج (`database/`, `handlers/`, `utils/`, `webapp/`) با
   `__init__.py` رسمی شد تا با importهایی که همه‌ی فایل‌ها از قبل استفاده
   می‌کردند (`from database.db import ...`, `from handlers.product_handlers
   import ...`, `from utils.invoice_file import ...`) هماهنگ باشد.

## فازهای پیاده‌سازی‌شده

- ✅ فاز ۱: فاکتور جدید (ثبت مشتری، انتخاب/جستجو، اقلام، هزینه ارسال، تخفیف،
  پیش‌نمایش، ثبت، خروجی فایل)
- ✅ فاز ۲: مدیریت فاکتورها (لیست، جستجو، جزئیات، ویرایش پیش‌نویس، ابطال،
  وضعیت پرداخت، پرداخت جزئی، خروجی PDF حرفه‌ای)
- ✅ فاز ۳: گزارش‌های مالی (درآمد روزانه/هفتگی/ماهانه با مقایسه رشد، نمودار،
  پرفروش‌ترین/کم‌فروش‌ترین، مجموع تخفیف، مجموع هزینه ارسال)
- ✅ فاز ۴: CRM (لیست مشتریان، پروفایل با تاریخچه خرید، رتبه‌بندی برترین
  مشتریان، یادداشت)
- ✅ فاز ۵: محصولات و انبار (افزودن/ویرایش محصول، موجودی، کسر خودکار موجودی،
  هشدار موجودی کم، override قیمت در فاکتور)
- ✅ فاز ۶: تنظیمات (نام/لوگو/تلفن فروشگاه، پیشوند شماره فاکتور، پنل وب
  گرافیکی، بک‌آپ دستی و هفتگی خودکار به پیوی ادمین)
